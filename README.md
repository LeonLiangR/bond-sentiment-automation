# 一级市场情绪指数

用于生成债券一级市场情绪指数日报。选好数据日期后，程序会读取 DM 招标数据、调用 DQ 试算，并生成可直接用于汇报的**数据表、文字和图片**。

## 下载并打开

1. 打开 [最新版下载页](https://github.com/LeonLiangR/bond-sentiment-automation/releases/latest)，在 **Assets** 里下载名称以 `-win-x64.zip` 结尾的压缩包。
2. 把压缩包完整解压到一个文件夹，再双击 **一级市场情绪指数.exe**。`Source code` 是源码，不是运行包。
3. 日后更新仍用同一个下载页。将新版解压到新文件夹后运行，本机已有设置和历史会继续使用。

## 第一次使用

电脑需使用 **64 位 Windows 10 或 11**，并已安装 **DM、DQ，以及带 Wind 插件的 Excel 或 WPS 表格**。Excel 和 WPS 二选一即可。请先登录 DM、DQ 和 Wind，确认能正常使用 Wind 取数和 DQ 批量试算。

程序会尝试自动找到已安装的软件。如果提示找不到，点击右上角 **设置 → 重新检测**，也可以手动选路径。选好平时使用的 Excel 或 WPS 后保存。

## 生成日报

1. **数据日期**选 DM 简报里的招标日期。例如简报是今天早上发的、内容是昨天的招标，就选昨天。
2. 选择 **保存位置**，默认是桌面，然后点击 **生成当日报告**。运行期间请勿同时修改 DQ 批量试算方案。
3. 完成后，在右侧点 **数据表**、**汇报文字**或**汇报图片**查看结果，也可以点 **打开文件夹**。

如果失败，先展开 **运行记录** 查看卡在哪一步。DM 未就绪时，可以先打开 DM 确认能进入行情或资讯页面，再重试。若仍失败，向维护人员提供报错文字即可。

## 换人或换电脑时怎么续上历史？

交班同事在 **历史交接 → 导出历史** 保存 JSON 文件，通过团队内部渠道交给接班同事。接班同事点 **导入历史**，选择收到的文件，下次生成日报就能用补齐的历史画图。

公开下载包不附带业务历史。同一台电脑升级无需重新导入；重复导入不会增加重复记录，遇到同日数据不同的情况会保留本机记录并提示。
