# 月度历史交接

使用0.5.7或更新版本。界面“历史交接”显示已收录的日期数量和起止日期；导入、导出本身不需要启动DM、DQ、Excel或WPS。

1. 交班人完成本月最后一份报告后，点击“导出历史”，选择保存位置，默认桌面。文件名包含历史截止日期。
2. 将导出的JSON文件交给接班人。每次导出完整历史，接班人不需要逐月补导以前的文件。
3. 接班人点击“导入历史”，选择JSON文件，核对新增日期、同日冲突提示及界面上的日期范围，再按日生成报告。

导出内容包括日期、六档数量、新旧指数、样本量及已有历史文字，不含账号、登录状态、安装路径或原始逐券数据。请按团队内部资料管理要求传递文件，软件不会自动发送或上传。

导入按日期合并，只增加缺失日期。相同记录不重复添加；同日数据不一致时保留本机已有记录（包括预置历史），并提示冲突日期。接班人若需要更正已有日期，应先核对双方数据来源，不要直接反复导入期待覆盖。

新增历史前，已有本地历史自动备份到 `%LOCALAPPDATA%\BondSentimentAutomation\history-backups`。文件无效或存在执行中的报告时不会写入历史；正在生成报告时界面也会暂时禁用交接按钮。

导入完成后，下一次生成报告会使用补齐的历史绘图；已经生成的Excel、图片和最近报告不会自动重写。回溯日期生成报告时排除未来记录，历史不参与当日逐券评分及当日新旧指数计算。

交接文件与本机配置独立，可以更换电脑和安装目录。请保留完整JSON文件，不用Excel打开后另存；除软件导出的交接格式外，也兼容旧版有效历史JSON数组。
